# respan gateway UI

The web dashboard served by the gateway binary at `/ui/`: live requests,
providers, routes, and a playground for chat, realtime, images,
transcription, speech, embeddings and video through the gateway's own `/v1` endpoints. A React SPA (Vite,
TypeScript, React Router, TanStack Query, Tailwind and shadcn/ui) that talks
only to the admin API under `/ui/api` and the standard `/v1` endpoints.

## Develop

```bash
pnpm install
pnpm mock    # a fake gateway on 127.0.0.1:8080 (no Rust needed)
pnpm dev     # http://localhost:5173/ui/, proxying /ui/api, /v1, /v1beta, /ws, /healthz to :8080
```

Or run the real gateway (`cargo run -p respan-gateway`) on `127.0.0.1:8080`
instead of the mock. `GATEWAY_URL=http://host:port pnpm dev` proxies
somewhere else.

The mock (`mock/server.mjs`, no dependencies) serves the admin API (overview with `reloaded_at`, MCP servers, requests
including tool-loop `steps`, and `POST /ui/api/reload`) with
generated traffic over the `/ui/api/events` stream, and fake chat (streamed),
image, transcription, speech, embeddings and video-job endpoints (a video
prompt containing "fail" makes its job fail). `MOCK_KEY=secret pnpm mock` requires a key, to exercise
the key prompt; `PORT=8081` and `MOCK_QUIET=1` (no generated traffic) also
apply.

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

## How the binary serves it

`pnpm build` writes `dist/` (not committed). The gateway embeds `dist/` at
compile time and serves it under `/ui/`, with `index.html` for any `/ui/*`
path that is not a file, so build the UI before building the binary. Config
`ui = false` turns it off. When the gateway has client keys, the dashboard asks
for one and sends it as `Authorization: Bearer` on every call; it is stored in
`localStorage` under `respan.gatewayKey`.

## Layout

- `src/lib`: the typed API client (`api.ts`, mirroring the contract), the SSE
  parser (`sse.ts`), chat streaming and formatting.
- `src/hooks`: queries, the live request feed, theme and media helpers.
- `src/pages`: one file per route; `pages/playground` holds a file per tab.
- `src/components/layout`: sidebar, header and the key dialog;
  `src/components/ui` is generated by the shadcn CLI.
